# Interview Kit — 使用指南

> 目标岗位：银行 Director（Solution Lead / Architect，HSBC GCB4 / 渣打 Band 5 档）。
> 本目录是面试准备的**唯一入口**，替代旧版 `hsbc-head-of-ai-fast-recall.md`。

## 目录结构（按使用顺序编号）

| 文件 | 内容 | 何时用 |
|---|---|---|
| `01-position-and-strategy.md` | 人设 / 岗位画像 / 面试官意图 / 核心策略 / 组织层与带队模型 / 诚实边界 | 面试前 1–2 天通读，确立自我定位 |
| `02-framework-and-buckets.md` | 三桶框架 + 答题骨架 + 场景→桶映射（Control / ROI / Engineering 三个深桶） | 遇到宽问题的通用骨架；背熟三桶 |
| `03-story-rag-orchestration.md` | 主线脊柱（RAG→orchestration）+ 60秒/3分钟/五步版本 + harness 边界 + 两个深潜（orchestration / RAG 经济学） | 面试开场与被追问细节时 |
| `04-real-cases.md` | 7 个真实案例速记 + 口语版（30–60 秒/个，原则变具体） | 回答具体技术问题时引用 |
| `05-scripts-and-qa.md` | 开场 / 高频题速答 / 12 个强答案 / 判断力短语 / 保命句 / 收尾观点 | 面试当天现场检索 |
| `06-mock-rehearsal.md` | Mock 面试 QA + 红标记 + 演练清单 | 面试前 1 天朗读演练 |
| `07-cheat-sheet.md` | 面试前 20 分钟：最薄、最密、指针式 | 面试前 20 分钟 |
| `08-self-introduction.md` | 自我介绍（Tell me about yourself）：90–120 秒口语版 + 45 秒压缩版 | 面试第一问，与 `01`/`03` 一起练 |
| `09-post-mortem.md` | 面试复盘：实际被问了什么、哪里冷场、下次怎么改（会回喂 `01`/`04`/`05`） | 面试结束后立即 |

## 快速路径

- **还有 1 天**：读 `01` → `02` → 练 `03` 的 60 秒版。
- **还有 2 小时**：过 `04` 案例 + `05` 高频题。
- **还有 20 分钟**：只看 `07`，它是全文最浓缩的指针。

## 面试后复盘（Post-Interview）

> 面试结束后立即写 `09-post-mortem.md`，记录：实际被问了什么、哪个答案冷场、哪个桶被深挖、对方如何回应、下次该改什么。
> 两次面试之间用复盘结果更新 `01`/`04`/`05`，比每次从头写 prep 高效得多。

## 三条贯穿主线（全目录统一记忆）

1. **控制面先于能力**（Control plane before capability）
2. **可预测账单**（Predictable bill and predictable operating outcome）
3. **边界设定比编码更值钱**（Boundary-setting > code throughput）

> 收尾观点：Bank AI deployment is not primarily a model problem. It is a control-plane, workflow, and ROI problem.
