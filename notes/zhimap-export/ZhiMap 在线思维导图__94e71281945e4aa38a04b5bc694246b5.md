# ZhiMap
在线思维导图
- ZhiMap是什么？ (link: https://zhimap.com/)
  - 在线思维导图工具
  - 知识分享社区
- 有什么用？
  - 记读书笔记
  - 写提纲、列计划
  - 知识整理
- 功能强大
  - 富文本编辑，
字体与颜色任意设置
    - 插入图片
      - gif动图也行
    - 数学公式 ∫−∞∞e−ax2dx=πa \displaystyle \int_{-\infty}^{\infty}e^{-ax^2}dx = \sqrt{ \frac{ π }{a} } ∫−∞∞e−ax2dx=aπ
    - 备注支持 markdown
      > 直接输入markdown语法即可
  - 多人实时协作
    - 历史版本
      - 私密导图
  - 导出高清图片，方便打印
    - 还能导出word文件！
  - 手机微信、PC电脑上打开浏览器即可使用
- 还有更多
  - 支持切换主题颜色，夜色背景也支持了！
  - 快捷键很丰富，手不离键盘就可以完成大部分编辑操作。
  - 分享到社交网络和手机微信都很方便。
  - 各种小图标
  - 强大的复制、粘贴功能
    - 多个导图之间通过ctrl＋c，ctrl＋v自由转移数据
    - 从其他网页通过ctrl＋c复制多行文字，
直接ctrl＋v即可自动生成导图节点！
  - 更多使用帮助 (link: https://zhimap.com/mmap/acc0be7b9de94a18bab0ef80cc10c33c)
