**重跑口径**（在工作 repo 执行，补上分支/commit 后方可作引用依据）：

```bash

  | awk '/^A:/{who=substr($0,3)} /^[0-9]/{add[who]+=$1} END{for(w in add) print add[w], w}' | sort -rn
# feature 分支插入量按顶层目录分解

  | awk -F'\t' '{split($3,p,"/"); s[p[1]]+=$1} END{for(k in s) print s[k], k}' | sort -rn
```

**工作方式（本人描述）**：一个模块一个模块改 → 跑测试 → 跑 example script → 对齐 docs → commit。docs 不是交付物，是自己的工作记忆；每次 commit 前对齐 docs，本质是强迫自己想清楚。

**这批数据对 §三残差的升级**：

1. **残差 1（Java 读数）有了量化形态**：~5k 逻辑跨语言不变＋~5k 语法税随语言变——"结构是资产、代码是渲染"第一次有了口径分离的数字对。仍封顶 UAT 收尾，且 5k/5k 是估计，引用前需实测。
