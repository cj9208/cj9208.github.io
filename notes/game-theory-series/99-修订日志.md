# 修订日志（博弈论系列）

规则（2026-10-21 定档，详见 [01-验证与总纲写作计划.md](./01-验证与总纲写作计划.md) §2.4）：

- **改的是事实**（日期、罚单金额、法条数字、引注）→ 正文静默改，不进本表。
- **改的是立场**（结论、判据、结构标签）→ 正文静默改，本表留一行。
- 知乎首发版本不回改，本站一律为现行版；本表记录的是"本站在哪天因为哪个模型改了口"。

存在的理由：博客同时是预测装置，靠带日期的旧判断核对结构判断的命中率。立场类改动若只留 git 痕迹，将来分不清"当时真这样认为"和"改过所以看起来一直这样认为"。
